
# Campus Bites - Canteen Pre-Ordering System

## Project Overview
Campus Bites is a Python-based web application that allows students
to pre-order food from their college canteen.

## Objectives
- Reduce waiting time at the canteen.
- Allow students to browse food and prices.
- Calculate order totals automatically.
- Allow students to select pickup times.
- Help canteen staff manage menu items and order statuses.
- Explore recommendation logic as part of AI-era coding.

## Technologies
- Python
- Streamlit
- SQLite
- AI-assisted development

## Features
- Food menu
- Shopping cart
- Student checkout
- Order history in the database
- Admin menu management
- Order status management
- Budget-based food recommendations

## How to Run
1. Install Python.
2. Install dependencies using:
   python -m pip install -r requirements.txt
3. Run:
   python -m streamlit run app.py
4. Open http://localhost:8501 in your browser.

## AI Usage
AI tools were used to assist with code planning, implementation,
debugging, and explanations. The current recommendation feature
uses rule-based Python logic rather than an external AI model.

## Limitations
This is a student prototype. It does not include online payments,
real-time inventory tracking, or protected administrator login.
